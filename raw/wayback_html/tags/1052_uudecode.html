                    Copy a file over SSH without SCP
                
    
                
    
					
    
                    I have come across multiple situations where I could only get to a server from a very restrictive bounce point which would not allow file transfers.  I was able to uuencode a file, copy the output to a text file over putty, and then uudecode the file to transfer it.  This works with any kind of file. 
                                    Show Sample Output
                					
    
                
    

				
    
					
    
						This is sample output - yours may be different.
					
    
					
    
						
    On the source server:
~$ cat test.txt
testing uuencode
~$ uuencode test.txt test.txt
begin 644 test.txt
1=&5S=&EN9R!U=65N8V]D90H`
`
end


On the destination server:
~$ cat test.txt.uu
begin 644 test.txt
1=&5S=&EN9R!U=65N8V]D90H`
`
end
~$ uudecode test.txt.uu
~$ cat test.txt
testing uuencode

port scan using parallel

				
It takes over 5 seconds to scan a single port on a single host using nmap
$ time (nmap -p 80 192.168.1.1 &> /dev/null)

real    0m5.109s
user    0m0.102s
sys     0m0.004s

It took netcat about 2.5 minutes to scan port 80 on the class C
$ time (for NUM in {1..255} ; do nc -w 1 -z -v 192.168.1.${NUM} 80 ; done &> /dev/null)

real    2m28.651s
user    0m0.136s
sys     0m0.341s

Using parallel, I am able to scan port 80 on the entire class C in under 2 seconds
$ time (seq 1 255 | parallel -j255 'nc -w 1 -z -v 192.168.1.{} 80' &> /dev/null)                                      

real    0m1.957s
user    0m0.457s
sys     0m0.994s
